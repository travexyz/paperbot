# Documentazione

PaperBot è un bot Telegram sviluppato utilizzando telegraf.js.

## Funzionalità principali

- [X] **Gestione utenti**: PaperBot usa un semplice sistema per registrare utenti e gestirli tramite il pannello dedicato.
- [X] **Gestione prodotti**: Gli amministratori possono aggiungere, modificare ed eliminare prodotti dal negozio semplicemente.
- [X] **Configurazione bot**: Gli amministratori possono anche gestire velocemente la configurazione del bot come nome del negozio, valuta e Messaggio del Giorno.
- [X] **Broadcast**: PaperBot permette di usare la fuzione "broadcast" per trasmettere messaggi di testo a tutti gli utenti, ciò può essere utilizzato per scopi pubblicitari per esempio.
- [X] **Pannello di amministrazione**: Gli amministratori possono accedere a un pannello dedicato per gestire gli utenti, i prodotti e molte altre cose.

## Installazione

Per installare e avviare PaperBot, segui i seguenti passaggi:

1. Clona il repository da GitHub: `git clone https://github.com/travexyz/paperbot.git`
2. Naviga nella directory del progetto: `cd paperbot`
3. Installa le dipendenze: `npm install`
4. Configura il file di configurazione `.env` con le tue credenziali e impostazioni.
5. Avvia il bot: `npm start`

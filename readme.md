# PaperBot - Documentazione

PaperBot è un bot Telegram sviluppato utilizzando telegraf.js. È progettato per fungere da negozio online e utilizza un database per gestire utenti e prodotti. Il bot offre numerose funzioni per gli amministratori, con un pannello dedicato facile da usare.

## Funzionalità principali

- **Gestione utenti**: PaperBot usa un semplice sistema per registrare utenti, gestirli, modificare il loro credito o bandirli.
- **Gestione prodotti**: Gli amministratori possono aggiungere, modificare ed eliminare prodotti dal negozio semplicemente.
- **Configurazione bot**: Gli amministratori possono anche gestire velocemente la configurazione del bot come nome del negozio, valuta usata e Messaggio del Girno.
- **Broadcast**: PaperBot permette di usare la fuzione "broadcast" per trasmettere messaggi di testo a tutti gli utenti, ciò può essere utilizzato per scopi pubblicitari per esempio.
- **Pannello di amministrazione**: Gli amministratori possono accedere a un pannello dedicato per gestire gli utenti, i prodotti e molte altre cose.
- **Basato su database**: Gli utenti e i prodotti sono basati interamente su database.

## Installazione

Per installare e avviare PaperBot, segui i seguenti passaggi:

1. Clona il repository da GitHub: `git clone https://github.com/travexyz/paperbot.git`
2. Naviga nella directory del progetto: `cd paperbot`
3. Installa le dipendenze: `npm install`
4. Configura il file di configurazione `.env` con le tue credenziali e impostazioni.
5. Avvia il bot: `npm start`
